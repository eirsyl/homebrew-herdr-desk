# Herdr Desk

Releases and the Homebrew cask for Herdr Desk, a macOS app for [Herdr](https://herdr.dev), the agent multiplexer.

```sh
brew install --cask eirsyl/herdr-desk/herdr-desk
```

Or download the `.dmg` for your Mac from [Releases](https://github.com/eirsyl/homebrew-herdr-desk/releases). The app updates itself.
